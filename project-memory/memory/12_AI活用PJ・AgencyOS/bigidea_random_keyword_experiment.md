2026-10-08、中村さんの仮説「ランダムキーワード(5〜10語)を起点にするとAIからぶっ飛んだBig Ideaが出る」を検証。
成果物: `Work/GBC_戦略企画部/GBCインテリジェンス／知見機能/01_AI活用/Project_AI業務活用PJ/20261008BigIdea_ランダムキーワード検証/`(2026-10-08にClaude作業フォルダから移動)(00_検証結果サマリー.md, gen_keywords.py=228語の日本語名詞プール8割+/usr/share/dict/words 2割をos.urandomで抽出, score.py)。
架空ブリーフ「創業180年の酒蔵×20代」。新規性(5点満点) 通常2.2 → 5語3.4 / 10語3.5、Big Idea候補(新規性・戦略接続とも4以上) 0 → 2 / 4本。外れ案も0→3〜4本に増えた。
(第1回・自己採点)効いたのは負の感情・社会的緊張を帯びた語(倒産・葬式・喧嘩)。英語の難語は弱い。
限界: 自己採点で1試行のみ。対照条件D(キーワードなしで大胆さだけ指示)は未実施。
**第2回(同日、別プロセスで実行し条件を伏せて採点)で覆った**: お題3つ×4条件×3回=360案、案出しSonnet・採点Opus(採点2回の相関0.83)。D「ぶっ飛べ」指示のみが新規性3.6・Big Idea候補率10%・上位案36本中24本で最も強かった。キーワード(旧B/新しい緊張感リストE)は新規性2.6〜2.8(通常は2.0)だが戦略接続が下がり、候補率は1〜3%。Dの代償は実現性2.5・リスク案率32%。第1回の差は大胆さの指示と自己採点によるものが大きかったと判断。round2/ に再現用一式(run_gen.py / run_judge.py / analyze.py)あり。案出しは `claude -p --tools "" --settings '{"disableAllHooks":true}'` を無関係なディレクトリで実行すると記憶やCLAUDE.mdが混ざらない(--bareはAPIキーが必要で使えない)。
**第3回(同日)**: F=大胆さの指示＋緊張感のある言葉5語(1つのプロンプトで同時に指示)は上乗せ効果なし。450案を再採点した結果、新規性はDと同じ3.3、戦略接続2.6、上位案はDの18本に対し12本、リスク案29%。Opusによる発想の型の分類では、Fの型数はD(42)より少ない36。E単独はDに無い型を最多の16型(案の34%)出した。
**中村さんの元々の課題意識(デッキ冒頭に明記するよう指示あり)**: AIに頼むとそつない・安全でそれなりに良い案が出るが、AIらしくない強い案を出さないと競合に負ける。ランダムキーワードを発想した理由は「ゼロから考えると一番近い山に登ってしまうが、それが最適とは限らず、もっと高い山があるかもしれない」という山登りの比喩。結論は本人の言葉で「AIは既にそれも含めて網羅していて、『ぶっ飛んで』というプロンプトの方が良い」。

**How to apply:** AIでBig Ideaを出すなら、まず大胆さを指示する。キーワードは主役ではなく補助として扱う。1つのプロンプトで大胆さとキーワードを同時に指示するのは逆効果。D(大胆さの指示)を主軸に、Eを別の回で走らせて合流させるのが推奨(合流方式そのものは未検証)。人による採点はまだ。関連: [[ai_katsuyo_pj_weekly_tips]] [[gbc_intelligence_engine_project]]
