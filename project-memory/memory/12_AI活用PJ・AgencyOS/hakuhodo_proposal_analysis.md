[[ai_shinsain_project]]の一環として2026-08-04に実施。博報堂が書籍・メディアで公開している企画書・アイデア発想法を、4系統のサブエージェント(書籍/Web記事/フレームワーク用語/電通比較)で調査し、`Work/AI企画書審査エージェント開発/博報堂企画書分析_エッセンス.md`にまとめた(旧フォルダ名`Work/AI審査員プロジェクト/`から移動済み)。

**最重要の発見(2026-08-04にユーザー本人が確認・訂正)**: 博報堂OB須藤亮氏の「リボンフレーム」(拡散思考×集約思考)、博報堂ブランドデザイン宮井弘之氏の「黄金の方程式」(事実＋課題整理＋解決策＋感情)が、ユーザー既存の[[proposal_writing_framework]](リボン思考、3ファクト+解釈)と用語・構造の両面で強く符合していたのは偶然ではなく、**ユーザー本人が博報堂の公開情報をWebでリサーチする中でこれらを見つけ、自分の企画書フレームワークとして採用したのが出典**だったため。つまり「リボン思考」「3ファクト+解釈」は電通純正のフレームワークではない。一方、電通側で同等に体系化・書籍化された一次資料は今回の調査範囲では見つからなかった。

**Why**: 博報堂は組織公式の単一フォーマットは持たないが、「生活者発想」という企業哲学(観察→解釈→表現、1981年〜生活総研)を土台に、個人(OB・社員)の著書を通じて企画書メソッドが多数対外発信されている。これが本プロジェクトの背景仮説「電通は言語化・外部発信で後れを取っている」を裏付ける材料になった。

**注意すべき誤帰属の訂正**(調査で判明、今後別の場面でも誤らないよう記録): SIPSは博報堂発ではなく**電通発**(2011年、佐藤尚之氏)。9segsフレームワークは博報堂発ではなく**M-Force社独自**(博報堂は活用パートナー)。AISASも**電通発**(2005年商標登録)。

**How to apply**: 博報堂関連の企画書・マーケティング手法について聞かれた際はこのファイルとエッセンスファイルを参照する。ただし個人著者発のメソッド(リボンフレーム等)を「博報堂公式の標準メソッド」と断定しないこと — 一次情報では明言されておらず、帰属には留保がある。岡本欣也氏・谷山雅計氏は博報堂在籍を裏付ける一次情報が見つからず、博報堂関係者として扱わないこと。
