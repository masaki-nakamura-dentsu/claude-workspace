2026-10-13開始。石井憲吾さん(クロスチーミングBX)と山田さんが進める **BX Planner - Lite ver**(Dify, https://udify.app/chat/KNCZ6QwPe3LQoOav、8ステップでOpportunity Brief作成、英語UI)をAI for Growth Canvasへ載せる計画があり、その前段として「海外社員がBXを理解・提案できる人財を増やす」施策を中村さんが相談された(Global Qでアクセスを伸ばした実績を買われて)。山田さんいわく「まずBXって何?が理解されていない」。

**現状診断の要点(2026-10-13)**: dentsudot BXサイト(https://www.dentsudot.com/sites/bx/SitePageModern/105155/global-bx-home)は会社案内型で事例・相談窓口・最初の一歩がない。動画173views、ソリューション記事は4〜16views、数字・Creds・研修資料は2024〜2025年のまま、ソリューションの半分に「(日本)」表記、日本語機械翻訳で著者名まで誤訳。著者は大久保卓哉・兒島理華・解明明。BX Plannerの注意書きに「日本国外での利用は各拠点が判断」とあり、海外展開の障壁。

**施策案の骨子**: 知る→自分事化→最初の一歩→提案→受注→共有の6段で詰まりを潰す/最初の対象は日系クライアント担当の海外拠点メンバー/シリーズ「聞くに聞けないBX」(4コマ・90秒動画・事例カード・しくじり集・Door Opener Questions・BX Clinic・BX Monthly英文メルマガ)/サイトを目的別に再構成/各拠点BX Champion/KPIはGBC KPI「BX含むプロダクト・サービスのグローバル展開件数(年39件)」に接続。
