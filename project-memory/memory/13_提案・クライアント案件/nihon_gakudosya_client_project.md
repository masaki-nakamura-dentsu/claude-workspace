クライアントは「株式会社日本学道舎 妙蓮寺校」(横浜市港北区仲手原2-45-14、東急東横線妙蓮寺駅徒歩3分)。2026年4月1日開業の民間学童保育で、空手(日本チャンピオン宮國淳氏)・華道(古流理苑会家元瀬尾理祥氏)・書道・合気道・俳句・やまと英語・茶道(不定期)など「本物のプロ講師から日本文化を学ぶ」ことを軸にした完全インクルーシブ料金の学童。創業者は峯川航氏(奈良県出身、一級建築士、バリのアマンリゾート体験がきっかけ、延暦寺会館の空間デザインを担当した縁あり)。コアターゲットは妙蓮寺駅周辺の小学1〜3年生の母親(25〜40歳)。

**Why**: 2026-08-27、ユーザー(電通・中村正樹氏)がこの会社の経営を軌道に乗せるための戦略コンサルを依頼。開業タイミングの出遅れにより在籍児童がわずか6名で、損益分岐に必要な60〜70名まで10倍の集客が必要という切迫した経営課題があった。11月には翌年度の学童がほぼ決定してしまうため、8〜11月が集客の勝負期間。

**How to apply**: 今後この案件が続く場合、以下を参照する。
- 一次情報(ボイスレコーダー文字起こし・書き殴りメモ)は `Photographer/Client/日本学童舎/` に保存されている(フォルダ名は「学童舎」表記だが正式社名は「学道舎」)。
- 公式サイト https://nippongakudosya.jp/ はStudio.Design製のNuxt SPAでJavaScript描画のため、通常のWebFetch/curlでは中身が取得できない。[[claude_playwright_setup]] のPlaywright環境(`NODE_PATH=~/.local/share/claude-playwright/node_modules node script.js`)でレンダリング後に`document.body.innerText`を取得する必要がある。料金ページ(/3)・講師紹介(/4)・QA(/QA)などは個別URLに直接遷移可能。
- 2026-08-27に提出した戦略提案書は `Photographer/Client/日本学童舎/提案書_日本学道舎_事業再起動プラン_20260827.pptx`。推奨コンセプトは「学道場化」(社名の「道」を核にプログラム名を統一)、コア施策は①学道場化ブランド統一②12週間集中集客ファネル③法人協賛。パートナーシップ候補として寺子屋てぃだ(連携候補、即着手)、崎陽軒創業家系の会場(秋イベント候補)、妙蓮寺(要紹介経由の慎重接触)、延暦寺(創業者の個人的な縁、思想連携)がある。
- サイトのQAページに記載矛盾あり(要修正提案済み): 対象学年「1〜6年生」表記 vs コアターゲット訴求「1〜3年生」、「完全インクルーシブ」訴求 vs 「特別講師授業は別途費用の場合あり」の記載。
- 提案書構築で見つかったpython-pptx技術的な落とし穴は [[dentsu_pptx_template]] に集約済み(プレースホルダーのleft/width崩壊バグなど)。
