**応募資格の重要要件（公募要領2-(8)）:** 「セルビアの現地法規制等の情報を入手できる体制を構築している（例：セルビアに関連会社または協力会社がある、セルビアに精通した人材に協力依頼できる体制を構築しているなど）こと」— 基礎点必須項目（0点で1項目でも不合格）。評価基準書でも「業務実施体制(1)体制表」(30点、うち加点20点)の中に「日本国内及びセルビア共和国において円滑な業務遂行が期待できるか」、「業務実績」(15点、うち加点10点)に「本業務に特に役立つ実績とネットワークを有しているか」があり、現地ネットワークの記載が加点にも直結する。
