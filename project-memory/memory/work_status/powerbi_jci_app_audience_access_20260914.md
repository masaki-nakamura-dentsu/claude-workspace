# PowerBI: JCIダッシュボードの限定公開(Appオーディエンス)

## 2026-09-14T00:00:00Z(セッション通算)
Status: in progress
What: KGI/KPIレポート内のJCI関連6ページ(JCI_All_Pitches系)だけを他部署の人にも見せたいという相談から開始。Power BI Appの「複数オーディエンス」機能を案内し、JCI用オーディエンス作成・ユーザー追加までは実施できた。ただし①コンテンツ選択画面でページ単位の表示/非表示トグルが機能しない(展開はできるがクリック操作不可、表示崩れではなく機能的制約と判明)、②オーディエンスに追加したユーザーが既にワークスペースメンバーの場合、アクセス許可欄から消えて「ワークスペースのユーザー」欄に統合され、ワークスペース直接アクセス経由でページ制限をすり抜けられる、という2つの技術的制約が判明。ユーザーは上司と相談の上、回避策として「JCI専用の複製レポートを作り、そちらだけをJCIオーディエンスに割り当てる」方針に転換することで合意。合わせて、今後のPowerBI開発ファイルの保存先を`Work/GBC_戦略企画部/GBC_数字管理・業務管理(QBR)/PowerBIダッシュボード開発/`に統一する指示があり、変更前バックアップpbix(`KGIKPI レポート20260914.pbix`)がユーザーにより保管済み。Claudeが以前`Claude作業フォルダ/KGIKPIレポート_売上総利益リネーム/`に置いていた作業フォルダと、`Salesforce書き出し/GBC__c_項目とリレーション_20260827.xlsx`もこの新フォルダへ移動した。詳細は[[powerbi_dev_folder_location]]参照。
Next: ユーザーが複製レポート作成(Save as、データセット接続を保持)→JCI以外のページを削除→AppのコンテンツにJCI専用複製レポートを割り当て、を実施する予定。次回このタスクが再開したら、複製レポートが実際にライブデータセットと接続維持できているか、JCI用オーディエンスのユーザーが正しくJCIページのみ見えるかの確認をサポートする。
