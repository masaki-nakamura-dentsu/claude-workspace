## 根本原因の再整理
CASE捏造の根本原因は、知識検索がTop K=10(Difyプランの上限)で8ファイル(cases/knowledge/faq/pm/
tools/case_expert/overseas_staff/task_briefing)を1回の呼び出しで横断検索しているため、
`cases_apac_01.md`のような巨大ファイル(408.6k語)内の特定の完全一致レコードでも、他ファイルの
チャンクと競合してTop 10に入らないことがある。ルールで「CASESセクション必須」等と要求される
ため、検索結果が薄い/ズレている場合にモデルが埋め合わせで捏造する構造的リスクがある。
