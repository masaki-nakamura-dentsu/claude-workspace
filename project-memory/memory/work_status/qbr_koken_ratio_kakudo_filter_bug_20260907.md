# QBR貢献度%乖離(PowerBI vs Tableau)調査

## 2026-09-07T00:00:00+09:00
Status: in progress
What: Tableau(`4. QBR_貢献実績 V1.0.twb`)とPowerBI(`GBC数字管理レポート (1).pbix`)で貢献度%が乖離(2026年13.3% vs 22.2%、2025年23.1%)している件を調査。pbixray(scratchpad内venvに新規インストール)でPowerBI側の`貢献度平均`メジューとPower Query M式を確認したところ、`貢献実績`テーブルのフィルターに9/6セッションで追加された`[確度]="A"`が混入しており、比率計算の分母(Group売総)だけを過少にしていることを特定。元Excel(`GBC 貢献実績_FY22 TO DATE.xlsx`)で全確度/確度Aのみの2パターンを実計算し、Tableau値=全確度、PowerBI値=確度Aのみと完全一致することで原因を実証。ユーザーに報告し、「では修正します」との返答を得た。
Next: PowerBI側(.pbix)の`貢献実績`テーブルM式から`[確度]="A"`条件を除去する具体的な編集手順を提示する。実際の.pbixファイル書き換えはユーザー本人が実施する方針([[feedback_token_conscious_powerbi]])。
