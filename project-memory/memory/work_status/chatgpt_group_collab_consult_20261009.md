# スタッフ相談: ChatGPTで複数人+AIの共同チャット 2026-10-09
Status: done
- 相談内容: 同じ資料でAIと各自チャットしているが互いの会話が見えない。グループ+AIで議論したい。ChatGPT(電通Enterprise)中心で。
- 調査結果: ChatGPTの「グループチャット」は2026-07-09以降新規作成不可(段階的廃止)。代替は「共有プロジェクト」(Business/Enterprise/Edu可)。メンバーはプロジェクト内の全員のチャット・ファイル・指示を閲覧可、各スレッドに作成者名。
- 回答: 第1案=共有プロジェクト+運用ルール(決定事項ログ.mdを資料に入れて更新)。第2案=Webアプリ自作(社内API/ガバナンス要確認)。実装はまだしていない。
- 追加Q&A: (1)共有プロジェクト内で作ったチャットは自動で全員に見える(外で作ったチャットはプロジェクトへ移すと見える) (2)決定事項ログへの自動保存はできない。ただし共有するとプロジェクト専用メモリが自動でONになり、同じプロジェクト内の他人のチャットをAIが参照できる(確実ではない、元に戻せない)。確実にするには会の終わりに「決定事項まとめて」→ファイル差し替えの半手動運用。
- 実機試験(2026-10-09): 共有したプロジェクトの内容は全員に見える(画面の表示文で確認)。プロジェクト限定メモリでは別チャットの内容を拾え、外には漏れない。決定事項ログも自動でまとめられた。デフォルトメモリでは個人メモリに入って外に漏れた→テストの1件は削除済み。2人での試験はまだ。詳細はproject_chatgpt_group_collab_consult.md。
- 2026-10-10: Gmailの無料アカウントで2人での試験を試みた→Enterpriseのプロジェクトには社外アカウントを招待できない(何も表示されずに外される)。個人Macに maxakisan-bot/9230 を新しく作った。
