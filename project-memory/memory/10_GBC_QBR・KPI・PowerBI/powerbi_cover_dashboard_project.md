3. **新規Feedback確立**: [[feedback_dax_one_measure_per_code_block]] — チャットUIのコピーボタンは1コードブロック全体をコピーしてしまうため、Claudeは今後DAXメジューを渡す際、複数メジューを1つのコードブロックにまとめず、必ず1メジュー=1コードブロックで提示すること。このプロジェクトに限らず今後の標準ルール。
4. **列名は旧Excel時代のドキュメントを信用しない**: [[powerbi_migration_gbc_dashboard_koken]]に書かれた`貢献実績`/`貢献見込`の列名(`月別集計用/GBC貢献売総(計上)/Attrib. Rev(Rec.)(JPY)`等の長い名前)は2026-08のSalesforceオブジェクト直結移行前の情報で、実際には`貢献売総_計上`/`Group売総`/`貢献度`のような短い名前にリネームされていた。今後このテーブル群の列を参照する時は、必ず正樹さんにフィールド一覧のスクリーンショットで実際の列名を確認してもらってから式を書くこと(推測でハードコードしない、[[powerbi_gbc_dashboard_current_state]]§6-3の教訓と同種)。
5. **【新規・重要】前年比メジューの「YTD vs フル年」ミックスアップ**: `前年比_CAS`を`CALCULATE(SUM(...), 計上年=SelectedYear-1)`とだけ書くと、前年側は(既に年間を通じて確定している実績なので)12ヶ月分フルで合計されてしまう一方、今年側は`表示合計_CAS`の「実績」部分が年初来のYTD(まだ8ヶ月分)しか無いため、フル12ヶ月 vs 8ヶ月という不当な比較になり、大幅マイナスの前年比(実例: -43.7%)という誤った数字が出た。**修正**: 前年側も「今年のデータが存在する最大月」までに絞り込む必要がある(`MAX([月番号2])`を今年で計算し、前年側を`月番号2 <= その値`でFILTER)。月/年関連の列をFILTER(ALL())で使う際は、DAX計算列ではなくPower Query native列(`月番号2`)を使うという既存の教訓([[powerbi_gbc_dashboard_current_state]]§5-4)と合わせて適用する必要がある。**この種の「単一のYTD累計値 vs 単一の前年値」を比較するメジューを新規に作る時は、必ずこの月数制限を最初から入れること。** 既存の設定_月別_前年比等のページ(月/四半期ごとに前年同月・同期を並べるチャート)はこのバグの対象外(そもそも期間が揃っているため)。JCIのWon前年比/Lost前年比も同じ修正が必要(未着手、次回JCI着手時に対応)。

# 前年比メジュー修正版(次回そのまま貼り替え用)

```
前年比_CAS = 
VAR SelectedYear = CALCULATE(SELECTEDVALUE('Raw YTD'[計上年]), ALL('四半期'), ALL('月'))
VAR MaxMonthThisYear = CALCULATE(MAX('Raw YTD'[月番号2]), FILTER(ALL('Raw YTD'[計上年]), 'Raw YTD'[計上年] = SelectedYear))
VAR PrevActual = 
    CALCULATE(
        SUM('Raw YTD'[売上総利益]),
        FILTER(ALL('Raw YTD'[計上年]), 'Raw YTD'[計上年] = SelectedYear - 1),
        FILTER(ALL('Raw YTD'[月番号2]), 'Raw YTD'[月番号2] <= MaxMonthThisYear)
    )
RETURN DIVIDE([表示合計_CAS], PrevActual) - 1
```

```
前年比_貢献 = 
VAR SelectedYear = CALCULATE(SELECTEDVALUE('Raw YTD'[計上年]), ALL('四半期'), ALL('月'))
VAR MaxMonthThisYear = CALCULATE(MAX('貢献実績'[月番号2]), FILTER(ALL('貢献実績'[年度]), '貢献実績'[年度] = SelectedYear))
VAR PrevActual = 
    CALCULATE(
        SUM('貢献実績'[貢献売総_計上]),
        FILTER(ALL('貢献実績'[年度]), '貢献実績'[年度] = SelectedYear - 1),
        FILTER(ALL('貢献実績'[月番号2]), '貢献実績'[月番号2] <= MaxMonthThisYear)
    )
RETURN DIVIDE([表示合計_貢献], PrevActual) - 1
```

# メジュー命名規則(2026-09-05確定、正樹さんがリネーム実施)

表示が紛らわしかったため、以下の規則に統一:
- 予算との比較(比率、100%基準) → **`予算達成率_XXX`**(旧`達成率_XXX`)
- 前年同じ期間(経過月まで)との比較(比率) → **`対前年同期比_XXX`**(旧`前年比_XXX`/`前年達成率_XXX`)
- 前年フル年(通期)との比較(比率) → **`対前年度比_XXX`**(貢献側はこちら。`貢献実績`テーブルが経過月と無関係に通期計上済みのため)

**現時点の確定メジュー名**:
- CAS: `予算達成率_CAS`(旧`達成率_CAS`)、`対前年同期比_CAS`(旧`前年比_CAS`) — 値125.5%

- いずれも計算式は`DIVIDE(表示合計, 比較対象) `のみ(旧`-1`版から変更、差分%ではなく比率%表示に統一)

**JCI着手時の命名判断**: `JCI_Pitch_Base`が「経過月まで」型か「通期計上済み」型かをまず月次内訳で確認し、`対前年同期比_Won/Lost`か`対前年度比_Won/Lost`のどちらかに合わせる。予算が無いため`予算達成率`系は作らない。
