2026-08-21、[[powerbi_migration_gbc_dashboard]]の新規マトリックスページで「マイナスの数字を赤字にしたい」という要望に対応した際に判明。

## 症状

セマンティック モデルの測定値プロパティ「書式」→「ユーザー設定」で `#,##0;[Red]-#,##0` のようなExcel/カスタム書式コードを入力しても、レポート上では`[Red]-174,817`のように**`[Red]`がそのまま文字列として数字の前に表示される**(色として解釈されない)。ドロップダウンが正しく「カスタム書式コード入力」モードになっていない、または本環境でこの入力欄が期待通りパースされない不具合と思われる(根本原因は未特定)。

## 確実な代替策: visual側の条件付き書式(ルール)

メジュー単位のカスタム書式ではなく、visual(マトリックス/テーブル)側の条件付き書式を使うと確実に動く:

1. 対象visualを選択 → 書式ペイン(ローラーアイコン) → 「セルの要素」
2. 対象の値フィールドの横の fx ボタン → 「フォントの色」
3. 「スタイルの書式設定」= **ルール**
4. 「適用先」= 値と合計(合計欄も含めて色付けしたい場合)
5. 「基準にするフィールド」= 対象メジュー
6. ルール条件: 開始 **「≥(以上)」+ 最小**、終了 **「<」+ 0 + 数値** → 結果の色を赤に設定
   - 開始条件を「>」のままにすると、データ中の**最小値そのもの(最もマイナス幅が大きいセル)が範囲から漏れて赤字にならない**ので、必ず「≥」に変更すること。

この方式は当該visual単位の適用になる(メジュー書式のようにレポート全体へ自動伝播はしない)ため、他のvisualにも赤字表示をさせたい場合は同じ手順をvisualごとに繰り返す必要がある。
