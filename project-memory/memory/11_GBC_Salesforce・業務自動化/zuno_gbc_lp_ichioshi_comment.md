中村さんはGlobal Q編集部員として、ZUNOのGBC向けLP（https://esq365.sharepoint.com/sites/dentsuZUNO/SitePages/lp_GBC.aspx）の「今月のイチ推しナレッジ」に「編集部員のコメント」を書く（毎月3本、他の書き手は榎本・百々・佐藤文・中牧ら）。
書式: 200字程度（2026-10-07ユーザー指定）、です・ます調、読者への問いかけや具体データ1〜2点→使いどころ→「ぜひご一読ください」系で締め、末尾に（中村正樹）。
**How to apply:** ZUNO個別ナレッジ（#/knowledge/id=NNNN）は直URLだとトップに戻る。共有ブラウザ9226でサイトトップを開いてから location.hash を設定すると表示できる（[[shared_bot_browser]]）。Global Q自作コンテンツ（例: GLOBAL ICE-BREAKING NEWS）は原本がOneDrive「Global Q_資料：情報アーカイブ」にあるので、そこから中身を読む方が早い。2026-10-07にICE-BREAKING NEWS 10月号の推薦文を作成。
