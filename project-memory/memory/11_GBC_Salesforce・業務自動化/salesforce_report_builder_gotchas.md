# 行レベル数式の項目ピッカーに出ないフィールドがある

2026-08-27、GBC案件/Itemsの`GBCGMauthorize__c`(ラベル「GM承認/Auth.」)で発生。このフィールドは:
- オブジェクトマネージャ上に実在し、既にレポートの列として追加済み(合計行にも表示される)
- にもかかわらず、「行レベルの数式列を編集」ダイアログの項目パネル(検索・フォルダツリー両方)には出てこない

原因は未確定(項目レベルセキュリティ、レポートタイプの参照経路制限、チェックボックス型固有の制限、のいずれか切り分け未了)。同じオブジェクトの別チェックボックス項目(`GBCGMConfirmed__c`)で同様に出るか試すのが切り分けの第一歩(試していない/結果不明のまま別解に回避した)。

**回避策(今回採用・成功)**: 条件付きSUM数式を諦め、代わりに**レポートの列グルーピングを二重にする**(外側グループ=対象のチェックボックス項目、内側グループ=もう1つの分類項目)。「チェックボックスTRUE × 分類X」のセルがそのまま「Xのうち承認済みのみの金額」になる。マトリックスレポートの標準機能だけで、数式なしに条件付き集計と同等の結果が得られる。

**Why**: 数式ピッカーの欠落原因を追わず実務を進める必要があった。二重列グルーピングは権限にもレポートタイプの制約にも依存しない確実な代替手段。
**How to apply**: 他のSalesforceレポートで「レコード単位の条件付き集計」が数式で作れない/フィールドが見当たらない場合、まずこの二重列グルーピング(またはさらに多重)で同じ結果が作れないか検討する。行レベル数式は最終手段ではなく、複数の選択肢の1つとして扱う。

# マトリックスレポートの「レコード件数」自動表示を消す場所

マトリックス(列グルーピングあり)レポートでは、明示的に追加していなくても各セルに「レコード件数」の行が自動的に一緒に表示されることがある。これを消す正しい場所は**レポート全体の設定(プロパティ)にある「行数」チェックボックスをOFFにする**こと。

**紛らわしい誤りやすい候補(実際は違った)**:
- 列グループ見出しの▼メニュー → 「昇順/降順に並び替え」「この項目で行をグループ化」「詳細列を作成」「グループを削除」しかなく、表示する集計値の切り替えはできない
- アウトラインパネルの「値」セクションを探す → このレポートでは該当セクションが見当たらなかった(バージョン/レポート種別による可能性あり)

**Why**: 上記2箇所を先に試したが空振りだった。ユーザーが自力で「全体の設定」内の「行数」チェックボックスを発見して解決した。
**How to apply**: 今後同様の「レコード件数を消したい」相談では、まずレポート全体のプロパティ(歯車アイコン等)内の「行数」設定を案内する。列グループの▼メニューやアウトラインの「値」セクションは筋が良さそうに見えて外れることがある。
