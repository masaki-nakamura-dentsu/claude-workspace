2026-09-03、ユーザー依頼「SalesforceのGBC過去1年in-out案件をExcelに書き出したい、主にどんなクライアントとin-out案件があったか知りたい」に対応して作成。

## データソース
新規にSalesforceへアクセスする必要はなかった — [[sf_reports_qbr_download_automation]]の自動パイプラインが既にダウンロード済みの「（設定突合用）SF案件リスト」レポート（`Work/GBC_戦略企画部/GBC_数字管理・業務管理(QBR)/Salesforce書き出し/（設定突合用）SF案件リスト/`）の最新ファイルをそのまま使用。ヘッダー行は12行目、データは13行目以降（27列、`GBC案件/Items: 作成日`等の列名はSalesforceレポートエクスポート特有の命名）。

## 「In-Out」の定義（商流/Business flow列、10列目=インデックス9）
値は単一または `;` 区切りの複合（例: "In-Out; Out-Out"）。観測された値: In-In相当なし、Out-Out / Out-In / In-Out / Japan / N/A / Investment とその組み合わせ。「In-Out」＝電通日本発の案件が海外拠点（GBC等）に流れる商流を指すと解釈し、**この文字列を部分一致で含む行**を対象にした（複合値も含める）。他の解釈（例:新規開始=In/終了=Outという案件ライフサイクルの意味）ではない点に注意 — もし将来「in/out」の意味が違う文脈で言及されたら、この列とは別物として扱うこと。

## 抽出条件（2026-09-03版、過去1年分）
- レコードタイプ（7列目）= `CLIENT`（`TASK`/`PROJECT`は内部活動でクライアント名が空のため除外）
- 商流列に `In-Out` を含む
- 作成日（`GBC案件/Items: 作成日`、文字列 `YYYY/MM/DD`）が実行日から過去1年以内
- 結果: 418件、ユニーククライアント203社（2026-09-03時点データ）

## 出力
`Work/GBC_戦略企画部/GBC_数字管理・業務管理(QBR)/GBC_InOut案件リスト_過去1年_YYYYMMDD.xlsx`（新規作成のため[[feedback_pptx_filename_versioning]]の上書き禁止ルールは非該当、日付は作成日）。2シート構成:
1. クライアント別サマリー（クライアント名・案件件数・Group売上/売総合計、件数降順）
2. 案件明細（案件ID/作成日/完了予定日/クライアント/案件名/部署/商流/フェーズ/責任者/売上・売総/地域/市場/事業区分/概要）

## 再実行する場合
同じ抽出ロジックを再利用可能。ビルドスクリプトはスクラッチパッド（セッション限りで消える）にのみ置いたため恒久保存はされていない — 次回同種の依頼が来たら、この抽出条件を再現するスクリプトを再作成すればよい（ロジック自体はこのメモに残してあるので再構築は容易）。定期実行の要望が出た場合は、[[sf_reports_qbr_download_automation]]のパイプラインに後処理ステップとして組み込むことを検討。
