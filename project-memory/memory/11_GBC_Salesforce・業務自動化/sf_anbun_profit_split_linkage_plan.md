- 利益スプリット登録アプリで受発注ヘッダNoを入れる→Crosstable(`Prep_CAS X SF Crosstable.xlsx`、ヘッダNo→案件ID)で案件IDを引く→按分情報の部署・割合を初期表示→GMが確認・修正して登録。

- 按分データはSF上の新項目になるので、実装後はPower BI(SF直結)から取得可能(中村さん確認)。
- 4部署以上の按分は**上位3部署のみ表示**でOK(アプリのスプリット先は3欄固定)。
