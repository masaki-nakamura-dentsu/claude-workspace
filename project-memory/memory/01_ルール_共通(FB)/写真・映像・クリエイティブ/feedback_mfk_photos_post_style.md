МФК PHOTOSのFBページ（https://www.facebook.com/MoscowPhotographersClub）向けの投稿文は、日本語のみで書く。ロシア語訳やバイリンガル構成、装飾的な文章は不要。

**Why:** 2026-09-05、椚田豊さんの「エルマー35展」出展紹介文で、ロシア語メイン+日本語訳+絵文字入りの案を最初に提示したところ、「過去の投稿のトーンと違う」と指摘され、過去投稿を参照して日本語のみの簡潔な事実ベースの文体に書き直した。

**過去投稿の実例パターン:**
- 短い出来事の報告文（1-3文）+「おめでとうございます」等の一言 → 記事/展覧会URL
- 写真展参加の場合は見出し「【写真展参加のお知らせ】」+ 本文1-2文 + 「■展示概要」ブロック（名称／出展メンバー／日時／会場／アクセス等を箇条書き）+ URL
- 絵文字は使わない。装飾的な形容や翻訳は付けない。メンバー名＋何をしたか＋詳細情報を淡々と伝える。

**How to apply:** 今後МФК PHOTOSのFB投稿文を作成する際は、必ずこの定型（見出し＋簡潔な報告文＋■概要ブロック＋URL、日本語のみ）に従う。他の言語版が欲しい場合はユーザーが明示的に依頼するまで付けない。

**例外: 木村顕悟さんの『まいにちロシア語』月例掲載投稿は専用の定型(2026-10-20指摘で確定)。** 上の「【見出し】+■概要」型は使わない。FB/IG本文:
```
МФК PHOTOSのメンバーである木村さんの写真掲載情報です！
---
<木村さんメールの(quote)〜(unquote)部分をそのまま>
```
公式サイト: タイトル「NHKラジオ『まいにちロシア語』N月号写真掲載」、本文「МФК PHOTOSのメンバーである木村さん / の写真掲載情報です！ / —– / 引用文」+写真ギャラリー、カテゴリー「掲載情報」、タグ「木村 顕悟」。
**Why:** 2026-09-17(10月号)に見出し+■概要型で作り、IGにはそのまま公開してしまった。10/20の11月号でも同じ誤りを繰り返し、本人に「過去の投稿フォーマットと異なる」と指摘された。**How to apply:** 作成前に必ず実投稿(FBページ・公式サイト ?p=3671 等)を見て書式を合わせる。メモリ上の下書きより実投稿を正とする。

**写会報告のサイト転載ルール(2026-10-20本人指示)**: 投稿日はFB元投稿の投稿日に合わせる(FB投稿ページHTMLの`"creation_time":<unix>`の最小値で取得)。受賞者名タグは既存がなければ新規作成。井熊浩登さんのタグは芸名「ジョニー森永」(既存タグ)を使う。
**FBページは2つある(2026-10-20本人指示)**: 公式ページ`facebook.com/MoscowPhotographersClub`に加え、写会報告などは`facebook.com/mowphotoclub`にも投稿される(9月度報告はこちらにのみあった)。報告の有無・未転載チェックは必ず両方を確認する。本文の井熊さん表記はFB原文(井熊 浩登)のままでよい、タグのみジョニー森永。
