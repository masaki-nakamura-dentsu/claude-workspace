駐在員から届いたネタを記事化するときは、本人の文章・言い回し(「とっても」「笑っちゃいました」「親族only」等)をほぼそのまま残し、つなぎの文と見出しを足す程度にとどめる。

**Why:** 2026-10-15タイ中島さん回で、内容は全部入れたが言い換えて整えた結果、ユーザーに「もらった話より短くなっている、なるべく入れ込みたい」と言われた(字数は原稿の方が多かったが、本人の語りが削られた印象になった)。

**How to apply:** 初稿から原文ベースで作る。本人の見出し(例「働き方のギャップと課題」)も活かす。補うのは途切れた文の補完と記事の型(冒頭あいさつ・突撃リクエスト・締め)程度。関連: [[globalq_whatsup_article_style]]
