[[ikeda_coaching_profile_photo_project]]の実撮影(2026-09-11、`/Volumes/Extreme SSD/20260911池田力さん撮影/`、98枚)で、Claudeが提案書の分析(高額帯コーチ=対角構図+腕組み等の意図的ポージング、低額帯コーチ=証明写真的な正面固定/完全プロフィール)を根拠に、正面固定ブロック(07850-861)・完全サイドプロフィールブロック(07886-897)・正面クローズドハンド/顎に手ブロック(07934-943)を「ブリーフに合わない低ランクパターン」として星1次セレクトの時点で丸ごと除外する案を出したところ、本人が並行して自分でLightroom上に星1を付け、「これを参考にして」「私の星の付け方を勉強して」と修正指示。本人の実際の星付け(37枚、Claudeの15枚を包含)を確認すると、**Claudeが除外した3ブロックすべてから本人も複数枚(正面固定3枚・プロフィール4枚・正面クローズド4枚)を選んでいた**。

**確認された基準:**
1. **提案書のスタイル分析(高ランク/低ランクの構図傾向)は、星1次セレクトの絞り込み根拠にしない。** 撮影セッション中に試した全てのポーズパターン(正面固定・対角+腕組み・完全サイドプロフィール・思考ポーズ・正面クローズドハンド等)から、**パターンごとに最低1〜数枚を必ず残す**。ポーズの優劣判断(どのスタイルを最終採用するか)は星1次セレクトより後の、少数候補への絞り込み段階で行う判断であり、初期カリングの段階でスタイルごと切り捨てるのは尚早。
2. **星1次セレクトの実質的な判断軸は「同一ポーズ内でのベストカット選び」(表情の自然さ・目が開いている・ピント)であり、[[feedback_photo_culling_criteria]]の「1シーン1枚」原則と同じロジックだが、"シーン"の単位がポーズパターン(セットアップ)ごとになる。** 明らかに無関係なカット(このセッションでは撮影データに紛れ込んだ夜の街スナップ4枚)だけが例外的にゼロ選定だった。

**How to apply:** 今後、複数ポーズパターンを試すスタジオ撮影(プロフィール写真・コーチング写真等)の星1次セレクトを代行する際は、提案書やブリーフのスタイル分析で「望ましい方向性」を把握していても、それを理由に特定ポーズパターンをこの段階で丸ごと除外しない。試された全パターンから均等に代表カットを拾い、スタイルの取捨選択は本人による最終候補への絞り込みに委ねる。無関係な混入カット(別セッションのスナップ等)の除外だけは初期段階で行ってよい。
