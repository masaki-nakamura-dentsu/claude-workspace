写真散歩などのスナップ撮影で「1シーン1枚」をセレクトする際の本人の判断基準。[[lightroom_cli_setup]]で読み込み・レーティングを自動化した際、Claudeの初回セレクト(29枚)に対し本人が5枚を修正、その理由が明確な基準として得られた。

**確認された基準:**
1. **主役でないものはフレームに入れない。** 配管などのディテール撮影で、主役以外の要素(奥の壁など)が写り込んでいるカットより、写り込みがないカットを優先する。
2. **幾何学的・シンメトリックな構図では、被写体(人物等)もその幾何学に沿わせる。** 高架下の柱回廊のようにシンメトリーが強い構図の場合、人物は中央寄りに配置されているカットを選ぶ(構図の幾何学性に人物配置を合わせる)。
3. **穴・窓越しなど額縁構図(フレーミングショット)では、額縁の奥に主題(人物等)が入っているカットを優先する。** 空白より、奥に配置される人物・要素があることで構図の意図(奥行き・視線誘導)が完成する。
4. **ピンボケは問答無用で非セレクト。** 他の基準より優先する足切り条件。
5. **「影」など特定の視覚要素を主題にした構図は、その要素が実際に綺麗に写っているかで判断する。** 意図(例:綺麗な影を撮りたかった)が撮れていなければ、そのシーンごと非セレクトにする(代替カットがなくても無理に残さない)。

**How to apply:** 今後の写真セレクト作業では、単に「ピントが合っている」「構図が良い」といった一般論だけでなく、上記5基準(主役の純度/幾何学への追従/額縁の奥の主題/ピンボケ即除外/意図の達成度)を優先的にチェックすること。特に2と3は「なんとなく良い方」ではなく明確なロジックがあるため、複数カットが拮抗する場面ではこの基準で説明できる方を選ぶ。
