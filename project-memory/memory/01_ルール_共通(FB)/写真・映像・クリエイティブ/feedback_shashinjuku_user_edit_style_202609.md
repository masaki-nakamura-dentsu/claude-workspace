2026-09-25、[[project_shashinjuku_shozoken_2026_update]]でClaudeが「右側に写真を枠内配置＋9ptクレジット」で作例を入れたところ、ユーザーが自分で次のように直した。次回以降の写真塾資料はこの形を最初から採用する。

- **作例はできるだけユーザー自身の写真**に差し替えられた(モンゴル・ウランバートル等の自作。Web/2021年版の写真は、報道カメラマン以外はほぼ全部置き換え)。Web写真は「自分の作例がない特定の被写体」(エッフェル塔の夜景、ドローン、生成AI画像、法務省リーフレット)だけに残った。→ まず本人の写真フォルダ・作例を探す/聞く。Webは最後の手段。報道カメラマンも後から自作(IMG_3088)を指定された。
- **写真は右側に全面配置(裁ち落とし)**: x≈7,248,525 / y=0 / w≈4,943,475 / h=6,858,000(スライド右約40%を天地いっぱい)。縦長トリミングで被写体を中心に置く(crop_left/right)。枠内に小さく置くのではない。
- **「2021年版資料より」等の自作写真クレジットは削除**。Web写真のクレジットだけは残る。
- **Q&Aスライド**: タイトル(Q.)を大きいマゼンタ太字にして縦中央付近(y≈2.1M)に置き、A.本文をその下(y≈4.3〜4.8M)に大きめ(24pt級)で。本文幅は写真の左(≈6.3M)。写真がないQスライドも縦中央寄せ。
- タイトルはマゼンタ太字(メイリオ24pt b=1)、本文24pt・キーワードは太字マゼンタ #CC0066、日付などの補足は18pt。箇条番号の「①②」は「1. 2.」に変更。
- 表紙はユーザー写真の全面背景+タイトル(マゼンタ)。セクション見出しにも写真を右側全面で入れた。
- ガイドライン図のような横長の図は、左に大きく(幅≈7.2M)置き本文を右に回す配置にした。
- 本文はnormAutofitに任せて文字量が多くても24ptのまま(qlmanageでははみ出して見えるがPowerPointでは縮小表示される)。
