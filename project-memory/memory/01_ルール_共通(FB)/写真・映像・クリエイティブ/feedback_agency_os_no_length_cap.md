Agency OS(ChatGPT Skill/Dify)の指示文で回答の文字数を制限しない。取れた社内情報(事例・駐在員・エキスパート・部署・ツール・アレココ資料・出典URL)は全件出す。読みやすさは結論先出し・表・見出しで確保し、削るのは聞かれていない一般論や繰り返しだけ。

**Why:** 2026-10-13に須田さんの「長い」という声を受けて「約3,000字目安・6,000字超は削る」を入れたところ、事例や駐在員情報が省かれるようになった。2026-10-15に中村さんが「文字数は制限せず、ちゃんと情報を提示して。情報を出すのがこのプロジェクトでとても重要」と指示。

**How to apply:** 「長い」という声には、情報を減らすのではなく構成(結論先出し・表・付録の整理)で応える。改修時は length/字数/budget 系の文言を入れない。[[agency_os_poc_feedback_20261013]]
