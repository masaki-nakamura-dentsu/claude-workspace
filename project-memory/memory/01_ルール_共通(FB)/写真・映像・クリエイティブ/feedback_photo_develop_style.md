[[walk_ryogoku_shimbashi_20260809_project]]で、Claudeが提案した現像案(カテゴリ別の一律補正)ではなく、本人が最終的に手動で仕上げた20枚の実際の現像設定を分析して判明したパターン。

**確認された手法:**
1. **トーンは「ハイライト↓シャドウ↑」で階調復元しつつ、「白レベル↑黒レベル↓」で締まりを再構築する2段構え。** ハイライトを一貫してマイナス(-17〜-81)にして白飛びを抑え、シャドウを一貫してプラス(+23〜+66)にして階調を持ち上げる。それだけだと眠い画になるため、白レベル(+4〜+50)・黒レベル(-14〜-45)で改めてコントラストの締まりを作る。単純な「コントラストを上げる/下げる」ではなく、この4点セットで階調を作り直すのが基本形。
2. **被写体の性格によっては意図的にこのパターンを反転させ、硬調でドラマチックに仕上げる。** 強い見上げ構図の建築や無骨な鉄橋など、力強さを出したいカットではハイライト↑シャドウ↓の通常と逆方向を選ぶ。パターンの機械的適用ではなく被写体判断が優先。
3. **シャープネスは一律40。** 印刷・コンテスト提出を意識した固定値と思われる。
4. **ホワイトバランスは写真ごとに個別調整。** 一律プリセットは使わず、色温度3400K〜7500K・Tintは概ね+5〜+30(マゼンタ寄り)の範囲で都度追い込む。
5. **Texture/Clarityは被写体次第で0〜47まで幅広く使い分ける。** 質感を強調したいカットにだけ強くかける。
6. **Vibranceは常にプラス(+8〜+15)、Saturationはほぼ0近辺に留める。** 彩度そのものを上げるのではなく、自然な色域を保ちながら鮮やかさだけ持ち上げるアプローチ。
7. **アスペクト比は「画角によっては1:1(スクエア)の方が収まりが良い」という判断で積極的に使う。** 元が縦位置(2:3)でも、構図が締まるなら大胆にスクエアへクロップする。実例では最終セレクトの85%(20枚中17枚)が1:1になった。
8. **幾何学補正(Upright系)は全カットに機械的に適用するのではなく、本当に必要な数枚だけに絞って軽くかける。** Claude側は「幾何学的な被写体は全て水平垂直を厳密に合わせる」という前提で臨んだが、本人は最終的に20枚中4枚にしか適用しなかった(むしろ傾き・パースを活かした構図を残す判断があった)。

**How to apply:** 今後写真コンテスト向けの現像を提案・代行する際は、上記1・4・6・7を基本形として提案し、被写体に応じて2(硬調反転)・5(質感強調)・8(補正を絞る)を判断材料に加える。「幾何学的なものは全部水平垂直を揃える」といった機械的なルール適用は避け、被写体ごとに本当に必要か判断すること。
