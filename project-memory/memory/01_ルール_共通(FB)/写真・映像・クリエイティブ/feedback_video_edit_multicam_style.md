マルチカム切替は「フレーズ等の区切りで、数秒〜数分間隔」。主に望遠カメラを使い、望遠が激しく動いている部分(パン・ブレ)は使わない。写真パートは静止のままではなく多少動き(ケンバーンズ)を付ける。プロジェクト改変前は別名保存。長い作業は「トークンを使わないよう工夫して」と言われた(2026-10-12)。
**Why:** 本人指示(2026-10-12、オペラ寄席東京)。
**How to apply:** 公演映像の切替案は音声の区切り+望遠の揺れ検出で自動生成し、画像確認は最小限(コンタクトシート1枚程度)に。
