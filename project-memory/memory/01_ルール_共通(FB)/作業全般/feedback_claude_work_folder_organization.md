## 削除について(重要な制約)
`rm`コマンドはAuto Mode classifierにブロックされ実行できなかった(destructive操作として拒否)。0バイトの完全重複ファイルであっても`rm`は通らない。**削除が必要な場面では、`Claude作業フォルダ/_削除候補(...)/`のような退避フォルダへ`mv`することで代替する**(reversibleなので許可される)。最終的な完全削除はユーザー自身に委ねる。

## How to apply
今後どのプロジェクトでも、ファイルを新規作成・保存する前に「これは既存のどのフォルダに属するか」を先に考える。属する先が無ければ`Claude作業フォルダ/<タスク名>/`を作成してから保存する。ルート直下への直接保存は避ける。他のMac(d14461等)でも同じDropbox構造なので同様に適用する。
