freee見積(AWIT)で交通費を「実費+管理費20%」で計算するのは内部ルールだが、比率は公にしていない。明細の注記には「北鎌倉⇔和田塚 往復」のように区間だけ書き、運賃内訳・「管理費20%」・実費額は書かない。

**Why:** 2026-10-05 TokyoLeaves見積(No.2026100502)で注記に「往復実費710円+管理費20%」と書いたところ、本人が「管理費の比率は公にしていません」と自分で修正した。過去の見積(2026081201)に比率入りの注記があったのを真似たのが原因。

**How to apply:** 交通費の計算自体は実費×1.2のまま行い、金額は単価欄にだけ入れる。計算の内訳はユーザーへの報告(チャット)でだけ伝える。過去見積の注記はそのまま真似しない。関連: [[freee_invoice_awit_business]]
