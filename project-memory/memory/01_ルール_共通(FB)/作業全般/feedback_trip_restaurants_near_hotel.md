旅程・しおりで飲食店を提案するときは、**宿泊ホテルから徒歩5〜10分圏を最優先**で探し、そこで見つからない場合だけ遠方を出す。有名店・ミシュラン店でもタクシー移動が要る距離なら候補から外すのが基本。

**Why:** 2026-09-27、楽麻呂師匠ホーチミン行程（[[rakumaro_hcmc_rakugo_project]]）で、ミシュラン掲載のクックガック（タクシー10分）やPhở Hòa Pasteur、Phở Quỳnhを提案したところ「遠いので却下、なるべくホテル周辺で」と修正を受けた。同行者が年配で移動負担を減らしたいのと、タイトな日程の合間の食事であることが理由。

**How to apply:** OSM Overpass（`around:800,<ホテル座標>`）でホテル周辺の飲食店を洗い出し、Web検索で営業状況・営業時間を確認してから提案する。距離（徒歩○分）は必ず明記する。
