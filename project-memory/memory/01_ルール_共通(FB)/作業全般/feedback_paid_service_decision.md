外部Webサービス(採譜サービス等)の利用を許可されたときも、有料プラン・買い切りチケットの購入は必ず事前に確認する。少額でも勝手に決めない。

**Why:** 2026-10-08、GBC新曲の楽譜化でKlangioが最良と判明し、1曲299円のチケットを推奨して確認したところ、ユーザーの回答は「課金しない」だった。無料の範囲で比較し、結果を手元の処理に取り込む方針を選んでいる。

**How to apply:** 無料枠で比較・検証 → 有料が必要な場合は、料金と得られるものを示して選択肢付きで確認する。「課金しない」が選ばれても、外部の結果(テンポ・コード・弾き方の傾向)を手元の処理の改善に活かす。[[music-transcription-pipeline]]
