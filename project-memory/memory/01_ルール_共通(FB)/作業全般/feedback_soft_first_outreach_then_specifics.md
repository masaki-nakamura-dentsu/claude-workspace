依頼メッセージの下書きを出した際、ユーザーは複数の具体的な質問（お名前や会社名を出してよいか、他に書けそうな実績はあるか等）を一度に投げる案ではなく、要件を共有しつつ「まずは事前の共有まで」「フォーマットが決まったら連絡します」で締める軽い一報を実際に送った（[[serbia_expo_beograd_2027_bid]] 参照、2026-07-28、平野さんへのセルビア万博案件の依頼）。

**Why:** 相手（平野さん）との関係性や、まだ社内フォーマットも固まっていない段階であることを踏まえ、いきなり重い依頼（お名前の使用可否の確認、資料提供の依頼等）をぶつけるのではなく、まず情報共有だけして温度感を伝え、具体的な依頼は後続のやり取りに回す方が良いと判断したもの。ドラフトにあった複数の質問（記載内容の可否確認、他の実績のヒアリング）や、過去に何度断られている依頼（AQUAFARM SEEの資料）は初手から外した。

**How to apply:** 外部協力者・パートナーへの依頼文面を下書きする際は、最初の一通は「情報共有+軽い温度確認」にとどめる案も選択肢として提示する。特に、(1) 過去に断られている/反応が薄い依頼は再度プッシュしない、(2) 個人名（役職者など）を提案書等の公式文書に使う話は、いきなり本文に含めず反応を見てから詰める、という段階を踏む傾向がある。次のアクション（フォーマット確定後の第二弾メッセージ)を下書きする際は、この案件では確定後に平野さんへ改めて具体的な依頼をする流れになる想定。
