`中村正樹/Work/` 以下の作業フォルダは、中村さんのDropboxアカウントで会社Mac・個人Macの両方に共有されている。会社Macで続けたいと言われても、同じ相対パスに保存すればよい。

**Why:** 2026-10-19、「会社Macでも同じフォルダ構造に保存されるように」と言われた。私は別アカウントだと思い込み、.claude-sync/shared_work へのコピーと会社Mac用のリンク作成タスクを作った。中村さんから「今のフォルダで大丈夫、Work内は私のアカウントで共有済み」と訂正された。

**How to apply:** Work以下の共有について聞かれたら、まず今のフォルダのままでよいと考える。仕組みを足す前に本人に確認する。古いメモリの「別アカウント」という記述(Nidecのフォルダ位置の話など)を一般化しない。[[dropbox_config_sync]] [[reference_mac_naming]]
