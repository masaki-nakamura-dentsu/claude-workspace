「Xにはアクセスできません、ご自身で確認してください」と返す前に、このMacに既にある経路(ログイン済み共有ボットブラウザ [[shared_bot_browser]] / [[claude_playwright_setup]]、ローカルエクスポート [[local_work_data_export]] など)を実際に試すこと。1回の浅い試行(WebFetchがログイン画面で止まった等)で諦めない。

**Why:** 2026-09-28の週次ログレビューで同型の躓きを2件確認。
- `1ddfd5f8` 2026-09-21: Vimeo動画の要約依頼 → WebFetchが認証画面で止まり「要約できません、字幕を書き出して渡して」と返答 → 本人「ログインしなくてもトランスクリプト見れるはずです」→ 自動生成字幕URLを見つけて要約成功。
- `053e5ad7` 2026-09-27: オペラ寄席の見積もり確認で「個人Gmailには直接アクセスできません、送信済みフォルダを確認して」と返答 → 本人「Gmailの検索もあなたの方でできるようにしてください」→ 共有ブラウザに maxakisan@gmail.com でログイン済みで直接検索できた。

**How to apply:** 「見られない」と言う前に、(1)ログイン済み共有ブラウザで開けるか、(2)ローカルエクスポートにあるか、(3)別の取得経路(字幕ファイル等)がないか、を試し、報告時は何を試したかを明記する。個人Gmailは共有ボットブラウザ経由で検索可能(2026-09-27確認)。

**追記(2026-10-13)**: 人物写真を探すときは、メール/Teamsのエクスポートにない古い資料ほどDropboxのオンラインのみ(0バイト)になっている。`find -size 0` で候補を洗い出し、PDFは `open -g -a Preview`、pptxは `open -g` で実体化させてから中身を検索する(qlmanage や cat では実体化しなかった)。木村啓太さんの写真はCasio G-SHOCK提案書(2025-02)にあった。
