ファイルへのリンクは、常にVS Codeのワークスペースのルート `/Users/d14461/dentsuDropbox Dropbox/中村正樹/` を起点にした相対パスで書く(例: `[名前.md](Work/GBC_戦略企画部/.../名前.md)`)。`../` は使わない。

**Why:** 2026-10-14、Bashでcdした後の作業フォルダを起点に `../../../../Work/...` と書いたため、リンクが開かなかった。cdすると環境上の作業フォルダが変わるが、VS Codeはワークスペースのルートを起点にリンクを解決する。中村さんから「今後も開くように気をつけて」と指摘された。

**How to apply:**
- リンク先はワークスペースのルートからの相対パスにし、前後にcwdが変わっていても使わない
- パスに半角スペースがあるときは %20 に置き換える(ルートの外の `dentsuDropbox Dropbox` 部分は相対パスに入らないので通常は不要)
- 大事な成果物はリンクだけに頼らず、`open -a "Visual Studio Code" <絶対パス>` で開いておく(`code` コマンドはこのMacに無い)
