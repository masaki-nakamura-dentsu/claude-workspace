2026-10-06、PowerBI構築手順のmdが「VS Codeだと読みにくい」と相談され、プレビュー表示(Cmd+Shift+V、横並びはCmd+K→V)を案内したところ「VS Codeのプレビュー表示がいいですね」と採用。

**Why**: 編集画面の生Markdownは記号が多く読みにくいが、別アプリのインストールは会社Mac(管理者権限なし)では手間。

**How to apply**: mdの手順書を渡して開くときは、VS Codeで開いた後プレビュー表示(Cmd+Shift+V)で読める旨を一言添える。表・コードブロックがプレビューで崩れない書き方にする。HTML変換や別ビューア導入は提案しなくてよい。
