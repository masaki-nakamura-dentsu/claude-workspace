単発プロジェクトのフォルダは `YYYYMMDD_名前`（例: `20261019_予算達成と稼ぐ力分析`）にする。恒常的なフォルダには日付を付けない。
**Why:** 2026-10-19、task-018で移したフォルダに日付がなく、ユーザーから指摘された。
**How to apply:** 単発の作業フォルダを作る・移すときは先頭に日付を付ける。日付は作成日または移動日にする。[[feedback_claude_work_folder_organization]]
