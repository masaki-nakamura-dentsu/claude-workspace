ユーザーに手作業を引き渡すとき(ChatGPT Skill/Dify ナレッジへのファイルアップロード、SKILL_Dify_for_paste.md の貼付、Power Automate/Power BI/SharePoint の設定変更など)は、**同じメッセージ内で「どう確認するか」まで渡す**: そのまま貼れるテストプロンプト(ChatGPT用・Dify用それぞれ)、またはどこを見ればよいか、正常時/異常時の見え方。

**Why:** 2026-10-05 の週次 CLAUDE.md レビューで、ユーザーが手作業を終えたあとに確認方法を毎回聞き直している状況が複数セッションで見つかった:
- 8b32504c (2026-09-29, Agency OS クレデンシャル): 「これが反映されたかどうかはどうやって確認すれば良い？」「私が確認したいのはそれがちゃんと機能するかのChatGPTやDifyでのプロンプト文です」
- ea09c319 (2026-09-29〜30, 同上): 「ヒットテスト何を入れたら良い？」「実際にChatGPTとDifyでプロンプト文で試したい。何と入れれば良い？」「テスト用のプロンプト考えて」「ChatGPT側の反映は何とプロンプト書いて出力してもらったら良い？」(1セッション内で4回)
- 40daba17 (2026-09-29, Power BI 出張管理): 「最終更新日の確認方法をもう少し丁寧に教えて」
- 3f326f97 (2026-09-16, Agency OS dentsudot): 「私の作業をもう少し丁寧に教えて」

**How to apply:** 「アップロードしてください」「設定してください」で終えず、続けて「確認用: ChatGPT に `…` / Dify に `…` と入力 → 〇〇が出れば OK、△△なら未反映」の形まで書く。手順はエンジニアでない人にもわかる粒度(どこをクリックし何を見るか)にする。関連: [[gbc_intelligence_engine_project]]
