2026-10-14 エアコン工事の依頼で、プロフィール(KNI)から始めた依頼フォームの最後の設問(利用のきっかけ)で「次へ」を押した時点で依頼が作成され、指名先+自動マッチの計5社から自動見積が届いた。その後に出た「利用規約変更のお知らせ/同意して送信する」はアカウント単位の規約同意で、依頼送信の手前ではなかった。私は「送信前で止めている」と誤報告し、ユーザーに「同意前に見積が来て不審」と思わせた。

**Why:** 送信済みかどうかを画面の文言(送信するボタン)だけで判断し、依頼一覧で実際の状態を確認しなかった。

**How to apply:** ミツモアで依頼を作る前に「指名しても最大5社に自動配信される」「電話番号入力後の最終設問で送信される」ことをユーザーに伝えて了承を得る。「送信前で止めた」と報告する前に、依頼一覧(meetsmore.com/requests)で依頼が無いことを確認する。くらしのマーケットはメッセージ相談で予約前に電話番号・住所を伝えると保証対象外になる点も併せて注意([[aircon_kamakura_replacement_202610]])。


**追記(同日)**: 依頼後のプロとのチャットは「日程リクエスト」送信後でないと開けない。「希望の日程を伝えてプロと話してみる」ボタンは押した瞬間に第1候補の日程でリクエストを送信する(確認画面なし)。さらに1社に日程リクエストを送ると、同じ依頼内の他社は「他の業者に決定済」となりチャット不可になる。複数社と並行して相談したいときは、日程リクエストを送る前にユーザーに「1社に絞られる」ことを伝えて選んでもらう。ボタンは中身を確かめる目的でも押さない。

**追記(2026-10-15)**: ミツモアのチャット送信ボタンを「textareaの6階層上の要素内のbutton[type=submit]」で探したら、同じ箱にある日程リクエストの送信ボタンを押してしまい、ユーザーが不要と言った訪問日程リクエストを誤送信した(取消ボタンなし→チャットで訂正)。送信ボタンは必ず `textarea.closest('form')` の中のものに限定し、押す前にフォーム内のボタン一覧に日程関連が無いことを確かめる。くらしのマーケットは form が無いので、textarea の3階層上(添付label+送信button 1個だけの箱)を使い、button が1個であることを確認してから押す。

**追記(2026-10-15)**: ミツモアのチャットでファイル選択した写真は画面上にimgが増えたが、実際には送信されていなかった(翌日スレッドに残っていなかった→ユーザーが手動送信)。画像の送信確認は、ページを再読込してからスレッド内に画像が残っているかで判定する(くらしのマーケットは再読込後にも残っており送信OKだった)。
