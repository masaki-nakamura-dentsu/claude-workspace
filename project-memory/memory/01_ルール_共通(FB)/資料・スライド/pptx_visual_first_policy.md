When building PowerPoint decks for this user, prioritize charts, diagrams, and photos over dense bullet text so a reader can grasp the point at a glance ("一発で分かるように").

**Why:** Explicitly requested (2026-07-09) when asking for a persuasion deck for local subsidiary presidents, with the instruction that this should be the default approach for future decks too, not just a one-off.

**How to apply:** Every content slide should carry at least one visual element (bar/donut chart, comparison diagram, table of concrete evidence, icon-based columns) rather than being bullets-only. Keep bullet text short and let the chart/diagram carry the main point. Use [[dentsu_pptx_template]] as the default template unless told otherwise.
