GBCの予算・見込の分析・資料では、確度(A/B/C)ごとの実現率で見込を重み付け・補正する方法を提案しない。
**Why:** 他の局は重み付けをしていないので、GBCだけ違う見せ方になる(2026-10-21の指摘)。ユーザーは「見込をどう当てるか」より「機会をどう増やすか」を重視する。
**How to apply:** 見込はそのまま扱い、予算との差は「要る受注・商談の数」で示す。打ち手は機会の入口(BP局からの相談、GBCからの提案、2件目・翌年、大型、海外発)で整理する。関連 [[gbc-budget-predictability-analysis]]
