**ユーザーが新機能の説明で挙げた具体例(タイトル名・国名・案件名など)は、あくまで仕組みの動作
イメージを伝えるための例示であり、その具体例自体のコンテンツを作り込む対象ではない。**

**Why**: 2026-09-30、[[anime_ip_search_dashboard_project]]で「クライアント提案用のタイトル詳細
(ターゲット層・訴求理由)を出す仕組みが欲しい。例えばBlue Lockをベトナムで売り込みたいとき」という
要望があった。これに対しBlue Lock×ベトナムについて複数回のWebSearchで深く調査し、ターゲット層・
文化的親和性・市場環境・懸念点・推奨アングルまで作り込んだところ、ユーザーから
「ブルーロックのベトナムはあくまで例なので、そこにこだわらないで下さい」と明示的な訂正があった。
仕組み自体(汎用的なタイトル×国のブリーフ機能)の実装は正しかったが、例示コンテンツの作り込みに
想定以上の時間をかけてしまった。

**How to apply**: 「例えば〜のようなとき」「〜を例にすると」という言い回しで具体例が示された場合、
それは要件を明確にするための最小限の手がかりであって、深掘りリサーチや完成度の高いコンテンツ作成の
対象ではないと解釈する。実装すべきは**その具体例が動く一般的な仕組み**であり、具体例そのものへの
投資は「仕組みが動くことを示す最小限の動作確認」に留める。ユーザーが実際にその具体例(または別の
組み合わせ)を本番で使いたいと明言した場合のみ、そこで初めて深掘りする。
