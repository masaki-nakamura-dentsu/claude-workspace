Nidec新社名の社内資料(2026-10-06)で指摘: 「広告会社なので『ネーミング』『ブランディング』というマーケティング用語をなるべく使って欲しい」。また「TEって何？」「カーライルは今回の案件と関係ある？過去の案件？」「判定役にカーライルが入っているのは何故？」と質問が出た。

**Why:** 社内チーム・クライアント向けに広告会社としての専門性を見せる語彙が期待されている。略称や関係性の説明不足は読み手が止まる原因になる。
**How to apply:** ブランド/社名案件の資料では「名前」→「ネーミング」、施策・浸透→「ブランディング」を優先。海外企業の略称(TE Connectivity等)は初出で「何の会社か」を一言添える。事例スライドは「本件か/別件の前例か」をキッカーやタイトルで明示。ステークホルダーの役割ラベル(判定役など)は根拠が分かる言い方にする。表記揺れ(コパル/COPAL)は作成時に統一ルールを決める。関連: [[nidec_components_naming_pitch]]

**2026-10-08 追加**: 共同編集ファイルの更新ルール — スライドは削除せず、不要なものは非表示にする。黄色ラベルがチームのフィードバック。クライアント提出形では「しかし、」などAI構文を避け、社内向け表現(アウトライン、RFPへの回答、見積レイヤー、社内参考の原価)を残さない。ネーミング案は1案1枚、順当から挑戦まで幅を持たせ評価を付ける。

**2026-10-08 第2弾(重要)**: スライドタイトルに結論を書かない(AIっぽく見える)。タイトルは「御社の競合について」のようなテーマ名、結論は本文の最後に置き、上から下に流れる構成にする。資料の作りはHINO提案書(電通の勝ち事例)のように文字少なめ・白地・中央タイトル・細線の図・黒地のステートメント。章タイトルもキャッチコピー調(「〜まで電通が担う」等)にせず短く説明的に(例「社名決定後のコミュニケーション」)。ネーミング案の振れ幅は「順当/挑戦」ではなくマーケ用語(記述型・示唆型・抽象型)で。競合のタグラインは必ず公式サイトで裏取り(TDKを誤記した)。調べた会社はAppendixに全社分析を入れる。1社だけ抜き出すスライドは理由を本文に書く。「空いているポジション=良い」と短絡しない(B2Bの業績データと研究で検証する)。
