When writing any 企画書 (proposal/planning document) for this user, always incorporate the following four frameworks, regardless of the specific topic or client.

**Why:** Explicitly instructed (2026-07-18) as a standing rule to apply to all future proposal documents, not a one-off request.

**Origin note (2026-08-04):** リボン思考 and 3つのファクト＋解釈 are not proprietary dentsu frameworks — the user found them himself while researching competitor Hakuhodo's publicly published proposal-writing methods (須藤亮's「リボンフレーム」and 宮井弘之's「黄金の方程式」) and adopted them as his own practice. See [[hakuhodo_proposal_analysis]] for the sourcing. Don't describe these as dentsu-original or as an independent coincidence with Hakuhodo's methods when discussing them (an earlier draft of the AI審査員プロジェクト企画書 mistakenly framed the overlap as unexplained/coincidental — corrected 2026-08-04).

**How to apply:** Structure and content should reflect all four elements below. This is complementary to [[pptx_visual_first_policy]] (visual-first slide design) — that governs slide-level presentation, this governs the underlying thinking/structure of the proposal itself.

1. **リボン思考・リボンフレーム**: Widely gather information (拡散/diverge) → narrow down to a core concept (収束/converge) → expand into diverse ideas from that concept (拡散/diverge again). Use this process to surface an original viewpoint that isn't bound by conventional wisdom (常識にとらわれない独自の視点).

2. **「1-3-1（イチ・サン・イチ）方式」**: Structure the presentation so it's simple to convey.
   - **1（目的）**: Narrow the goal (Why) down to a single one.
   - **3（コア）**: Narrow the core elements of the plan down to exactly three.
   - **1（まとめ）**: Conclude with a single Next Action — what should be done.
   - Within this, use **3つのファクト＋解釈**: facts alone don't create insight for the audience, so pair objective facts with an original "interpretation" (解釈) to present real insight.

3. **クリエイティブなストーリー性**: Craft the proposal — fonts, whitespace, colors, page composition — like a movie script, designed to move the reader's emotions, not just convey information.

When drafting or reviewing any 企画書, check that all four are explicitly present (not just implied) before considering it done.
