スライドを作る・直すときは、次の手順で「AIっぽさ」を消す(2026-10-08 ユーザーが「この方法を記憶して」と明示)。

1. タイトル = 中央のテーマ名「〜について」(名詞句)。言い切りの結論文をタイトルにしない。
2. タイトル上の小見出し(kicker「基礎情報 ①…」等)を置かない。
3. 結論は本文の最後に1行だけ(言い切り型で短く。2026-10-13更新 [[feedback_slide_text_iikiri]])。旧タイトルの言い切り文はここへ移す。
4. 色は白地・細線・黒/赤/グレー。ティールやオレンジの塗り箱・帯の表はやめ、罫線(hline)で区切る。赤は要所だけ。
5. 横の解説文は削る: 「ラベル(グレー小) + 数字(太字)」の組と、最後に一言だけ。「〜の今こそ〜意義がある」「〜の確かさを軸に」のような論説調は書かない。
6. 数字は「全体→技術職」のように比較の向きをラベル側に書き、数字行は「21% → 26%」だけにする(折り返しを防ぐ)。
7. Appendixも本編と同じ様式。追加先セクションの既存スライドが古い様式でも、それに合わせない。
8. グラフはデータを変えず、系列色(全体=薄グレー、主対象=黒、強調=赤)・サイズ・角丸枠なし(roundedCorners=0)だけ直す。

**Why:** 仮想調査Appendixを kicker+結論文タイトルで作ったら「本編と作り方が違う」「タイトルがまとめ文章になっていてAIっぽい」と指摘され、続けてCCS Appendixも同じ方法で直すよう指示された。

**How to apply:** Nidecデッキでは style.py の slide()/conclusion()/hline()/box() を使い、lib.content() は使わない。他案件のデッキでも同じ原則を適用する。文章面のAI臭は [[feedback_ai_smell_avoidance]]、案件の状況は [[nidec_components_naming_pitch]]。
