エグゼクティブサマリーには、課題の捉え方(問いの立て直し)、発見、戦略、実行の方針を書く。クライアントから聞いている現状、RFPの依頼項目(A/B/C)の作業内容は載せない。

**Why:** 2026-10-13 Nidec提案書で、ES1を「ご依頼/現状/考え方/相手」、ES2を「A新社名/Bロゴ/Cホームページの作業」にしたら「内容が良くない。考え方や戦略が重要。現状やABCの作業内容はクライアントにとって当たり前で提案のレベルではない」と指摘された。

**How to apply:** ESは「課題の捉え方→戦略→実行の方針」の順で、各ページに電通ならではの視点(問いの転換、データからの発見、判断の軸)を置く。作業範囲・費用の網羅は本編の進め方の章に任せる。[[proposal_writing_framework]] [[nidec_components_naming_pitch]]
