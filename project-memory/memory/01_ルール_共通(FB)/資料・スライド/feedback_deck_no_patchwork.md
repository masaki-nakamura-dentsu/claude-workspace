報告資料を更新するとき、新しい情報(Teamsの声、ログ分析など)を出どころごとのスライドとして継ぎ足さない。本編は「全体像→使われ方→評価→課題→対応→結果」のような1本の流れに統合し、出どころ別の詳細はAppendixに移す。課題と対応は件数・順番を揃え、「これから」と「済み」を混ぜない。

**Why:** 2026-10-15 Agency OS PoC報告で、アンケート/Teams/Difyログの各スライドを足していった結果、中村さんから「追加情報を着けてきていてツギハギに見える」と指摘された。

**How to apply:** 2回目以降の更新では、まず本編の筋を見直し、重複するスライド(例: 課題と「ログから見えた不足」)は統合する。古い前提が残った文言(例: 解決済みの相談事項)も同時に直す。[[feedback_deck_appendix_same_style]] [[feedback_pptx_edit_existing_not_rebuild]]
