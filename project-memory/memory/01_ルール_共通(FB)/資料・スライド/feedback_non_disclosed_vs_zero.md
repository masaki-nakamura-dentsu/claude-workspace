**ルール**: データパイプラインや資料で、ある項目を「確認したが公表資料に記載が無かった」場合、これを数値の「0」として記録・表示してはいけない。「0」は「その値がゼロである」という事実の主張であり、「情報が非公開・非公表である」こととは全く意味が異なる。

**Why**: 2026-09-29、[[gbc_intelligence_engine_project]]の電通クレデンシャル生成機能で、統合レポートに「クライアント数」の記載が無かったケースを、パイプラインが当初「クライアント数: 0件」のように表示していた。中村さんから「非公表を0件と表記するのは誤り」と明確な指摘を受けた。「クライアント数がゼロ」という誤った事実を電通のクレデンシャル資料に載せてしまうリスクがあった。

**How to apply**:
1. 「確認したが見つからなかった」項目は、黙って省略もしない(省略すると「確認し忘れた」のか「確認したが無かった」のか区別が付かなくなる)。
2. かつ数値の「0」でも代用しない。
3. 明示的な非公表マーカー(日本語なら「ー」、英語なら「N/A」や「Not disclosed」等)を使い、可能であれば「確認済みだが記載なし」という経緯も一言添える。
4. この原則は電通クレデンシャル案件に限らず、企業の公開資料から数値を抽出・集計する全てのデータパイプライン(業況レポート、KPI集計、財務データ抽出等)に汎用的に適用する。「取得できなかった値」と「値がゼロ」を常に区別すること。
