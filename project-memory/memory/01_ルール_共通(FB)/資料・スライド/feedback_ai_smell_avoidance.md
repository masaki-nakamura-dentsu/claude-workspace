## 核心
- 冗長がAI臭の最大要因。まず削る（目安400字）
- 過剰に懇切丁寧・全部MECEに網羅するのがAI臭の本体（言葉そのものより冗長さが問題）
- 回りくどい表現をやめ直球で書く
- 装飾（絵文字見出し・信号機3色表・太字乱用）で盛らない

## 消す単語・言い回し
- 空虚な強調: まさに／非常に／極めて／画期的／〜と言っても過言ではない
- カタカナ盛り: ソリューション／シナジー／シームレス／インサイト
- 名詞句化ビジネス語: 最適化／効率化／推進／実現 → 素の動詞に戻す（活用して→使って）
- 自己美化・スローガン: 寄り添い／伴走し／二人三脚で／さらなる高みへ
- 定型の枕・締め: この度は／昨今／まず結論から申し上げますと／ご確認のほどよろしくお願いいたします／いかがでしたでしょうか
- 過剰敬語: 〜させていただきます の乱用
- 空虚な相槌: 素晴らしいですね／おっしゃる通りです／さすがです（＝最初から正しく出す）

## 崩す構文
- 「結論→理由→まとめ」の三段固定、「ポイントは3つ」フレームの機械的多用
- 接続詞過多（また／さらに／加えて／したがって）を毎文頭に置かない（8割消せる）
- 「〜し、〜し、〜する」の三点セット・体言止め対句の連打
- ダッシュ「 — 」での補足連結多用 → 句点／「：」／括弧に置き換え
- 断定回避（〜と考えられます の連発）、受け身・名詞化しすぎ（〜の改善が図られる→〜を改善する）

## 逆側の正解
短い・1文=1行・要点だけ／正直に言い切る／数字・日付・選択肢を具体に出す／口語を1〜2箇所混ぜて完璧すぎる敬体を崩す／たまに「！」で温度を上げる

## 納品・送信前30秒チェック
1. 強調語・接続詞・枕・定型締めを削ったか
2. 記号・絵文字・太字装飾を撤去したか
3. 口語を1〜2箇所混ぜたか
4. 声に出して「自分が言う言葉」か
5. 長ければ400字目安で削ったか
