GBC幹部向け資料では数字とグラフを最優先し、分析グラフをなるべく多く載せる。数値にはすべて単位を付ける(期待値なら「百万円/件」、倍率なら「倍」、比率なら「%」)。「期待値」「カバー率」「実現率」のような指標は、式と具体例(例: 72%×2.32百万円=1.67百万円)を同じスライドに書く。

**Why:** 2026-10-17、予算予測と稼ぐ打ち手の分析をチャットで報告した際、「期待値など単位がない記述があった」と指摘された。あわせて「幹部は数字とグラフがとても重要」「経営初心者でも分かるロジックで」と指示された。

**How to apply:** チャットでの報告でも単位を省かない。資料ではグラフごとに「単位:」の表示か見出しに単位を入れ、読み方の一文(例:「100なら翌年は57が残る」)を添える。[[feedback_executive_deck_disclosure_and_brevity]] [[pptx_visual_first_policy]]

追記(2026-10-17): 幹部資料の流れは「やることを先に、優先度グループ別に示す → なぜなら、このデータ」の順にする。分析の順に並べない。最終目標(今年の残りでやること・来年の戦略)を冒頭で示す。チャットで提案した打ち手は、資料化のときに漏らさず全部入れる(局別浸透マップ・Out-In・負けた理由が抜けたと指摘された)。
