スライドの文言は言い切り型にする。「〜を置きます」→「〜を置く」、「〜がありません」→「〜がない」。

**Why:** 2026-10-13 BX拡散デッキでユーザーが自分で直したうえで「『ます』は止めて言い切り型にする。その方がAIっぽさがなくなる」と指示。[[feedback_deck_appendix_same_style]] の「結論は本文末1行・です・ます調」はこれで上書き(結論行も言い切り)。

**How to apply:** デッキ作成・修正時は結論行・注記・キャプションも含めて言い切りで書き、納品前に「ます|です|ません」で終わる段落を機械的に検索する。クライアントへの質問例など、話し言葉の引用だけは例外。[[feedback_ai_smell_avoidance]]
