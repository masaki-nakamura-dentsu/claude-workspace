Power Query Onlineのプレビュー画面には表示行数の上限があり、大きいテーブル(数千行)を目視で行数カウント・スクロール確認しようとすると正確な値が取れない。2026-08-18のセッションでこの制約のために「別の空クエリで確認」する方式に切り替えた実績があり、2026-08-19に再度同じ状況になった際、Claude側がこれを忘れて「各クエリのプレビュー画面で行数・合計を見て教えてください」と案内してしまい、正樹さんから「昨日も伝えた、覚えておいて」と指摘を受けた。

**How to apply**: 新旧クエリ(またはテスト用と本番用)の行数・金額合計を突合する必要が生じたら、最初から専用の空クエリを1つ作り、`Table.RowCount(<クエリ名>)` と `List.Sum(Table.Column(<クエリ名>, "<列名>"))` を比較したい全クエリ分並べた小さな結果テーブル(`#table({"クエリ","行数","合計"}, {...})`)を返す形で一括集計する。これらの関数はテーブル全体に対して計算されるためプレビューの表示上限に影響されず、結果自体も数行の小さな表になるので確実に全部読める。プレビュー画面で個々のクエリを開いて目視確認する案内は最初から避ける。
