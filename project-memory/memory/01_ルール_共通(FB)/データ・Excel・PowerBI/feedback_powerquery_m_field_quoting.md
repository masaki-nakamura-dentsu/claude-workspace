M言語で `[列名]` のようなフィールドアクセサ構文を書くとき、列名に `/`(スラッシュ)・スペース・日本語以外の記号などが含まれる場合は `[#"クライアント/Client"]` のように `#"..."` で囲む必要がある。素の `[クライアント/Client]` のように書くと `Invalid identifier` エラーになる。

**注意**: `{"クライアント/Client"}` のように**文字列リストの要素として**使う場合(`Table.SelectColumns`・`Table.RenameColumns`・`Table.ExpandTableColumn` の引数など)はこの制約を受けない、ただの文字列なので普通のダブルクォートでよい。問題になるのは `each [列名] = ...` のような**フィールドアクセサとして直接参照する場合のみ**。

**Why**: [[powerbi_migration_gbc_dashboard]] のプロジェクトメモにも既に「両方ともこのプロジェクトで複数回踏んでいる最頻出バグ」として記録されていたにもかかわらず、2026-08-24のセッションでClaude自身が集計検証クエリのコードで `[クライアント/Client]` と書いてしまい、正樹さんから「今後このエラーが出ないようにちゃんと思い出して下さい」と指摘を受けた。過去に記録していても実際にM言語コードを書く瞬間に思い出せていなかった。

**How to apply**: Power Query M言語のコードを書く・提示するたびに、`each [列名] ...` や `[列名]` を直接使う箇所は書いた直後に「列名に `/` や特殊文字・スペースが含まれていないか」を自己チェックする。含まれる場合は必ず `[#"列名"]` の形に直す。これは一度覚えれば終わりではなく、コードを書くたびに毎回確認する習慣として適用する。
